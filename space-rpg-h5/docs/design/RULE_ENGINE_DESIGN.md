# 🎮 规则引擎设计文档

> **一句话说清楚：** 让AI在游戏中自己"长出"新规则，而不是我们提前写死所有可能性。

---

## 📌 为什么需要规则引擎？

### 现在的问题

想象你在玩游戏，说"我想在这颗荒星上搭帐篷休息"。

**目前系统的反应：**
```
系统：❌ 你不在可休息区域（飞船休息舱/空间站旅馆）
```

因为代码里写死了只有两个地方能休息。**你每想到一个新玩法，程序员就得改一次代码。**

### 有了规则引擎之后

**新系统的反应：**
```
AI：你环顾荒凉的星球表面，凭借野外生存的经验，
    找到了一处避风的岩壁，搭起了简易帐篷...
    
    🆕 系统自动学到了：有"野外生存"技能 → 可以在荒星露营
    ✅ 休息成功（简易休息，恢复30%）
```

**AI自己发现了新规则，自己注册了，下次自动生效。不需要改代码。**

---

## 🧠 核心思路（三句话版）

1. **引擎 = 裁判**：只负责判断"这个条件满不满足"，不做其他事
2. **规则 = 卡牌**：每条规则就像一张卡，写着"什么条件下→产生什么效果"
3. **AI = 玩家**：AI在游戏过程中可以"打出新卡"（注册新规则），但必须遵守卡牌规则

## 📋 规则长什么样？

每条规则就是一张"卡片"，写着条件和效果：

### 示例1：飞船休息舱（系统预置）

```
📍 规则名称：飞船休息舱可以休息
🏷️ 所属系统：休息
📌 来源：系统预置（不可删除）

✅ 条件：
  - 当前位置标签 = "飞船休息舱"
  - 不在战斗中

🎯 效果：
  - 恢复100%生命
  - 恢复100%精力
  - 恢复50%护盾
```

### 示例2：荒星露营（AI运行时创建）

```
📍 规则名称：荒星露营
🏷️ 所属系统：休息
📌 来源：AI自动创建
⏰ 有效期：临时，3幕后过期

✅ 条件：
  - 当前位置标签 = "荒星"
  - 拥有技能"野外生存"
  - 拥有物品"帐篷" × 1

🎯 效果：
  - 恢复30%生命
  - 恢复20%精力
  - 消耗1个帐篷
```

### 示例3：黑市交易（AI在剧情中创建）

```
📍 规则名称：黑市解锁
🏷️ 所属系统：交易
📌 来源：AI自动创建（通过NPC剧情触发）

✅ 条件：
  - 商人公会声望 ≥ 50
  - 当前位置 = "织星暗巷"

🎯 效果：
  - 解锁违禁品交易
  - 价格比正规市场低30%
  - 但被巡逻队发现概率+20%
```

## 🔧 引擎能理解的"词汇表"

AI不能瞎编条件，只能用下面这些词：

### 条件词汇（AI能用来写条件的）

| 词汇 | 白话意思 | 例子 |
|------|---------|------|
| `at_location` | 在某个地方 | 在"织星空间站" |
| `at_location_tag` | 在某类地方 | 在任何"安全区" |
| `not_at_location` | 不在某个地方 | 不在"地球" |
| `in_state` | 处于某种状态 | 正在"战斗中" |
| `not_in_state` | 不处于某种状态 | 不在"战斗中" |
| `stat_gte` | 某个数值 ≥ 多少 | 生命 ≥ 50 |
| `stat_lte` | 某个数值 ≤ 多少 | 燃料 ≤ 10 |
| `has_item` | 拥有某个物品 | 有3个"能量块" |
| `has_skill` | 拥有某个技能 | 会"野外生存" |
| `has_trait` | 拥有某个特质 | 是"赛博改造体" |
| `reputation_gte` | 某势力好感 ≥ 多少 | 海盗好感 ≥ 30 |
| `reputation_lte` | 某势力好感 ≤ 多少 | 军方好感 ≤ -20 |
| `npc_present` | 某NPC在场 | 工程师张三在旁边 |
| `time_after` | 游戏时间过了某个点 | 2157年3月之后 |
| `act_gte` | 游戏进度到第几幕 | 第3幕之后 |
| `chance` | 随机概率 | 30%的几率 |

**AI如果写了一个不在列表里的词 → 直接拒绝，不会执行。**

### 效果词汇（规则能产生什么效果）

| 词汇 | 白话意思 |
|------|---------|
| `modify_stat` | 改变数值（加血、扣燃料等） |
| `add_item` | 给玩家物品 |
| `remove_item` | 拿走玩家物品 |
| `add_state` | 添加状态（中毒、隐身等） |
| `remove_state` | 移除状态 |
| `add_skill` | 学会新技能 |
| `unlock_location` | 解锁新地点 |
| `add_connection` | 开通新航路 |
| `register_npc` | 注册新NPC |
| `trigger_event` | 触发事件 |
| `show_message` | 显示消息 |

## 🛡️ 安全机制（防止AI搞破坏）

### 三道防线

```
第1道 │ 词汇检查：AI只能用上面表格里的词，编新词直接拒绝
      │ → 防止AI发明"一键秒杀所有敌人"之类的离谱规则
      │
第2道 │ 冲突检测：新规则不能和现有规则矛盾
      │ → 不能同时存在"荒星可以休息"和"荒星不能休息"
      │
第3道 │ 数量限制：每个系统最多100条规则，每回合最多注册3条
      │ → 防止AI疯狂灌入规则把系统撑爆
```

### 规则的权限等级

| 来源 | 能做什么 | 不能做什么 |
|------|---------|-----------|
| **系统预置** | 一切 | — |
| **AI创建** | 添加新规则、创建临时规则 | 不能修改/删除系统预置规则 |
| **任务创建** | 任务相关的临时规则 | 任务结束自动失效 |

### 自动清理

- **临时规则**：最多存活3幕，过期自动删除
- **数量上限**：全局最多500条规则
- **幕归档时**：清理所有过期规则

### ⭐ 规则晋升（临时→永久）

大部分AI创建的规则都是临时的，用完就扔。但**极少数有意义的规则可以晋升为永久规则**。

**什么样的规则值得永久保存？**

| 场景 | 举例 | 为什么值得永久 |
|------|------|---------------|
| 玩家付出了真实代价 | 花大钱买了"星际驿站通行证" | 花了钱的解锁不该消失 |
| 剧情里程碑 | 完成海盗王任务解锁"走私航路" | 剧情成就应该持久 |
| 重复验证有效 | 同一条临时规则被触发3次以上 | 反复使用说明是有效规则 |
| NPC关系突破 | 和商人成为好友解锁VIP折扣 | 社交关系不该随幕重置 |

**晋升机制（两种方式）：**

```
方式1：AI主动晋升
  AI在叙事中认为某个发现是"重大发现"时：
  [TOOL_CALL:promote_rule]{ruleId: "ai_rest_desert", reason: "玩家学会了野外生存并成功验证"}
  → 规则从 temporary:true 变为 temporary:false
  → 不再过期

方式2：自动晋升
  系统检测到某条临时规则被成功触发 ≥ 3次
  → 自动晋升为永久规则
  → 在叙事中提示："你对荒星露营越来越熟练了（规则已固化）"
```

**永久规则的限制：**
- 每个系统最多 **20条** 永久AI规则（系统预置不算）
- 达到上限时，最久未使用的永久规则会被标记为"休眠"
- 休眠规则不参与评估，但数据保留，可被AI重新激活

**保存位置：** 永久规则存入 `Lore.data.rules.permanent[]`，随世界观一起持久化到 localStorage。即使清除会话记忆，永久规则也不会丢失。

## 🌍 覆盖所有游戏系统

规则引擎不是只管休息的——它管**所有系统**：

| 游戏系统 | AI能自动拓展什么 | 举例 |
|---------|----------------|------|
| **休息** | 新的休息地点、新的恢复方式 | 在荒星露营、在盟友飞船上休息 |
| **交易** | 新商品、新市场、折扣 | 发现黑市、NPC给老客户打折 |
| **战斗** | 新武器效果、环境buff | 某星球重力低→跳跃攻击加成 |
| **导航** | 新航路、捷径 | 发现虫洞、获得秘密星图 |
| **技能** | 新技能、技能升级 | 反复战斗→学会"快速拔枪" |
| **NPC** | 新对话、新服务 | 和商人交易10次→解锁VIP服务 |
| **任务** | 新任务、隐藏任务 | 探索废弃空间站→发现神秘信号任务 |
| **飞船** | 新模块、新能力 | 安装隐形装置→可以潜入敌区 |
