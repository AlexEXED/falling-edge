# AI边界论

> *无法通过不可靠论证，论证不可靠论证。*

一个从游戏工程失败出发、经过认知追问、社会推演、环境批判、黑盒实验、最终停在哲学悬崖边的反思项目。

已终结。公开归档。在无人问津的角落，等待阅读。

---

## 背景

2026年4月，一个太空RPG游戏项目失败了。七天开发，纯AI驱动，写出来了，跑不起来。

复盘时发现：失败不是技术问题，是信任边界问题。于是一个技术复盘变成了一场追问——

AI应该在哪里？不应该在哪里？当你意识到你不该信任它的时候，你正在信任的那个判断本身呢？

追问了六篇文章，加一个附录，加一个终章，加一个对谈录，加一篇手写后记，加一个科幻短篇落款。

然后停了。
